# You're Gone

RetroPlay sets all its text in You're Gone by Ray Larabie (Typodermic), version 5.002,
PostScript name `YoureGone-Regular`, its upright weight (the family's italic isn't used, so
it isn't bundled). It vendors the font as `YoureGone-Regular.otf`, renamed from
`Youre Gone.otf` in `you-re-gone.zip`, downloaded from 1001fonts.com (the archive's
comment says so; the font file inside is unchanged).

- Archive SHA-256 (`you-re-gone.zip`): `9acd7561cca69258b7d1bdd6ea908b5bf94abd7cfcfa51f1f85d52db73c3c092`
- Font SHA-256 (`YoureGone-Regular.otf`): `1e1a01c9760372d50ba233822df234fe982552feb861aff585edcfb070f7066d`
- License: CC0 1.0 (public domain dedication, https://creativecommons.org/publicdomain/zero/1.0/),
  as the font's own name table states: "Released in 2024 under CC0 license. No rights
  reserved." Its license record is copied verbatim in `YoureGone-LICENSE.txt`.
- Embedding: OS/2 fsType 0 (installable).
- A capitals face: its lowercase keys draw the capitals, so the app shows text as written.

The app bundles this file as a resource and performs no runtime font download.
