# Oxanium

RetroPlay sets all its text in Oxanium by Severin Meyer. It vendors four static weights,
`Oxanium-Regular.ttf`, `Oxanium-Medium.ttf`, `Oxanium-SemiBold.ttf` and `Oxanium-Bold.ttf`,
from the designer's official release
[sevmeyer/oxanium 2.000](https://github.com/sevmeyer/oxanium/releases/tag/2.000)
(`oxanium-2.000.zip`, `fonts/ttf/`), the release Google Fonts ships (`ofl/oxanium`).
