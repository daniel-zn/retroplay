# Hydrogen Whiskey

RetroPlay sets all its text in Hydrogen Whiskey by Ray Larabie (Typodermic), version 5.011,
PostScript name `HydrogenWhiskey-Regular`, its one weight. It vendors the font as
`HydrogenWhiskey-Regular.otf`, renamed from `Hydrogen Whiskey.otf` in
`hydrogen-whiskey.zip`, downloaded from 1001fonts.com (the archive's comment says so; the
font file inside is unchanged).

- Archive SHA-256 (`hydrogen-whiskey.zip`): `2e6a8829a6526902809ae792bb0cfce5a3dbba221687fef40935d1da5639978c`
- Font SHA-256 (`HydrogenWhiskey-Regular.otf`): `4f4a1313a944eabcfde3c39692a3928f2c04065640e1353fca416057f07061c9`
- License: CC0 1.0 (public domain dedication, https://creativecommons.org/publicdomain/zero/1.0/),
  as the font's own name table states: "Released in 2024 under CC0 license. No rights
  reserved." Its license record is copied verbatim in `HydrogenWhiskey-LICENSE.txt`.
- Embedding: OS/2 fsType 0 (installable).

The app bundles this file as a resource and performs no runtime font download.
