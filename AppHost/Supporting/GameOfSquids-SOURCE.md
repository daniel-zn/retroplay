# Game Of Squids

RetroPlay sets all its text in Game Of Squids by Darrell Flood, version 1.00 (October 8, 2021),
PostScript name `GameOfSquids`, its one weight. It vendors the font file exactly as the
designer ships it, `GameOfSquids-1GMVL.ttf`, from the font's page on FontSpace
(https://www.fontspace.com/game-of-squids-font-f68476), unchanged and under its own name.

- Font SHA-256 (`GameOfSquids-1GMVL.ttf`): `3e31f5f6bd44bc1bdf8a6cda5d79648307f0b2502bdb155490a98debf417da89`
- License: freeware, "100% free for all use"; reselling the font files, and reformatting or
  converting them for resale or redistribution, aren't permitted. The app ships the file
  unchanged. The designer's license text is copied verbatim in `GameOfSquids-license.txt`
  (SHA-256 `a734b8a3e6f68e189e257ef058e2e3a10677ac1dc79c45590b91856919ca1cfd`).
- Embedding: OS/2 fsType 0 (installable).

The app bundles this file as a resource and performs no runtime font download.
