# RetroPlay

Native iPhone SwiftUI emulator with a Delta-simple library UX (tap a game to play — no RetroArch core menus), Liquid Glass UI, and a locked first set of systems:

- Game Boy Advance (mGBA)
- Nintendo 64 (mupen64plus)
- Nintendo DS (melonDS)
- PSP (PPSSPP, IR interpreter / no JIT)
